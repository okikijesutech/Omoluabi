# Contributing to Ọmọlúàbí

Thank you for your interest in preserving the Yoruba language! Ọmọlúàbí is a **Preservation-First** engine, and we welcome contributions from developers, linguists, and native speakers.

## Ọmọlúàbí Philosophy
Unlike "standardization" projects, Ọmọlúàbí treats every dialect and tonal variation as a first-class citizen. 

- **Preservation Over Standardization**: We never delete valid dialect data.
- **Tonal Integrity**: Tonal marks are non-negotiable data.
- **Earned Trust**: Authority is algorithmically earned through consistent, high-quality contributions.

## Technical Stack
- **Monorepo**: Turborepo
- **Frontend**: Next.js (App Router) + TailwindCSS
- **Backend**: NestJS + Prisma ORM
- **Database**: PostgreSQL

## Getting Started
1. **Fork the Repository**: Create your own copy of the project.
2. **Install Dependencies**: `npm install`
3. **Run Locally**: `npm run dev`
4. **Prisma Setup**: Ensure you have a local PostgreSQL instance and run `npx prisma generate`.

## Contribution Types
### 1. Linguistic Contributions
Use **The Forge** (Linguistic Lab) in the app to submit:
- **Lexical Units**: New words, phrases, or tonal variations.
- **Dialect Heritage**: Precise captures of regional variations (Ijebu, Ekiti, Yagba, etc.).
- **The Echo (Audio/Visual)**: Authentic oral recordings and cultural artifact imagery.
- **Archival Wisdom**: Proverbs, etymologies, and historical usage context.

### 2. Code Contributions
- **Bug Fixes**: Open an issue before submitting a PR.
- **Features**: For major features, please discuss your proposal in a GitHub Discussion first.
- **Testing**: Ensure all new code includes unit or integration tests.

## Code of Conduct
We are committed to a respectful and inclusive community. Please be kind and constructive in your feedback.

## Governance
All contributions must pass the **2-approval threshold** from trusted reviewers before being merged into the canonical knowledge base.
